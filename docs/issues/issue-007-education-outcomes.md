# Issue 007: Education and Outcomes

Status: planned

Depends on: Issues 004 and 006

## Outcome

A new user can set up agents and understand progress and the final result without reading repository documentation.

## Scope

- Add a How to Play button and modal.
- Explain game rules, registration, manual prompting, lack of in-app wake, and optional external prompting approaches.
- Display the current game turn count.
- Add a finish modal with win/loss, winning team/reason, total turns, New Round, and New Game.

## Acceptance

- Setup and turn-prompting caveats are understandable on-screen.
- Turn count matches clue-and-guess sequences.
- Every terminal game shows an actionable result modal.
