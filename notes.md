# SemanticSpy — future ideas

## Two-human play (not started)

- Make the game playable by two people without requiring a Codex agent.
- Keep the current cooperative format: one Spymaster and one Operative on the same side.
- Decide whether the first version should be shared-device/pass-and-play or separate browser sessions.
- Protect the Spymaster's key from the Operative; shared-device play will need a deliberate private-view handoff.
- Reuse the authoritative game rules and clear turn indicators. Treat human/agent control as a separate choice from Spymaster/Operative roles.
- Keep agent play available as an optional mode.

This is a future planning note only. No two-human mode, player registration, networking, or matchmaking is being implemented in the current update.
